
# Swiggy Sales Analysis – Excel Dashboard Project

## 📌 Project Overview
This project presents an end-to-end **sales analysis using Microsoft Excel**, where the entire workflow — **problem statement, raw data, analysis, and interactive dashboard** — is contained within a single Excel file.

The objective of the project is to analyze Swiggy sales performance and derive actionable business insights using Excel-based analytics and visualization techniques.

---

## 📂 Project File
- **Swiggy_Sales_Analysis.xlsx**

The Excel file includes the following sheets:
- **Problem Statement** – Business questions and analysis objectives
- **Raw Data** – Original sales dataset
- **Data Cleaning & Analysis** – Data preparation, calculations, and pivot tables
- **Dashboard** – Interactive Excel dashboard with KPIs, charts, and slicers

---

## 📊 Key Business Metrics
- **Total Sales:** ₹53.01M  
- **Total Orders:** 197K+  
- **Average Order Value:** ₹268.51  
- **Average Rating:** 4.34  

---

## 🔍 Analysis Performed
The analysis answers key business questions such as:
- How do sales trend monthly, weekly, and daily?
- Which food type (Veg vs Non-Veg) contributes more to revenue?
- Which states and cities generate the highest sales?
- How do sales, ratings, and orders vary across quarters?
- What patterns exist in customer ratings and order behavior?

---

## 📈 Dashboard Features
- KPI cards for quick performance tracking
- Monthly, weekly, and daily sales trends
- Sales by food type and geography
- Top-performing cities by sales
- Quarter-wise comparison of sales, ratings, and orders
- Interactive slicers for filtering by month, restaurant, and category
